## 一、项目背景与核心科学问题

在隧道涌水、坝基防渗与岩质边坡稳定性前期勘察中，工程现场最常问的核心问题是：**指定两个位置之间，地下裂隙网络到底通不通？**

然而现场观测极度有限（露头只见表面、钻孔只穿单线、井壁只看柱面切片）。同一份钻孔编录或表面点云往往对应多种同样符合观测的内部裂隙拼接方案——其中一个说「贯通」、另一个说「断开」（**等解释性 / Equifinality**）。若仅凭单一标称模型或浮点容差给出唯一答案，参数在测量残差内的微小波动就会导致通断结论无提示地翻转。

本项目不再「替不确定性投票」，而是正面回答两个核心问题：
1. **哪些通断结论在所有符合观测的可能状态（合法参数域）下保持不变？**
2. **当现有观测确实无法定音（同时存在通与断的合法反例）时，下一步优先去现场复核哪一片关键裂隙，才能最快消除分歧？**

## 二、核心方法架构

### 1. 保留真实几何的露头点云建簇
从无人机/激光扫描真实露头点云出发，按预注册规则切取无抽稀受控窗口，拟合并构建局部非正交有限多边形裂隙簇（每簇 6–9 片相距 $\le 0.5\text{ m}$ 的斜交裂隙），全程严守三条几何保真原则：
- **不填洞**：完整保留外环与真实拓扑内孔环，禁止用凸包糊死内部岩桥孔洞；
- **不直接吃自动分割碎片**：先做同源共面聚合，再作连通拓扑判定；
- **不压成正交矩形**：保留真实斜交产状（实测 490 对裂隙中 337 对显著非正交，占 68.78%）。

### 2. 三步精确有理连通性认证（四态输出）

```text
[第一步：由实测残差划定合法范围]
   残差尺度  σᵢ = mean(|rᵢ|) + std(|rᵢ|)
   法向平移  vᵢ = ±2σᵢ nᵢ,  t ∈ [-1, 1]  （两端锚片固定，叠加 ±3.95° 有理倾角微扰与边界互斥共 6 种模式）
         │
         ▼
[第二步：单状态连通性精确裁定（0.1 mm 有理网格 · 零浮点容差依赖）]
   ① 精确三维面片求交（分数算术求交线，切分拓扑不变的 POINT/OPEN 原子格）
   ② 构造无向接触图 G(V, E)（以裂隙片为节点、片间相交为连边）
   ③ A → B 广度优先搜路（BFS 可达判「通」并提取路径；不可达判「断」并提取零跨边 S/T 最小割）
         │
         ▼
[第三步：遍历全合法域（6 模式 × 全部原子格）汇总四态结论]
   ├── 确定贯通 (CERTIFIED_CONNECTED)                  → 全部合法状态均连通，附可逐点核查的连通路径
   ├── 确定断开 (CERTIFIED_DISCONNECTED)               → 全部合法状态均断开，附 S/T 最小割阻断墙
   ├── 有据歧义 (AMBIGUOUS_WITH_VERIFIED_WITNESSES)    → 同时给出连通见证 + 断割见证 + 稳定裕度 ρ
   └── 超预算拒答 (BUDGET_EXCEEDED)                    → 组合格数超出 4,096 格上限时如实拒答，不截断、不硬猜
```

- **为什么必须用精确有理数（分数）算术？**  
  真实露头簇（如 `jardim_c02`）中两片裂隙的最小标称间隙仅 **0.00297 m（2.97 mm）**。传统浮点求解器依赖人工设定的距离容差，容差微调即可无提示判反通断。本项目将坐标吸附至 $0.1\text{ mm}$（$1/10000\text{ m}$）有理网格（巴西簇最大欧氏量化界 $0.000248\text{ m}$，全 22 簇最大 $0.000640\text{ m}$），后续三维求交与图搜索全程采用分子/分母精确有理运算。

### 3. 零泄漏主动下一步复核（Active Next-Check）
针对判定为「有据歧义」的裂隙簇，排序器在**严格不读取隐藏真值标签（零泄漏）**的前提下，对每项候选现场复核动作（确认某片裂隙的产状倾角分支、边界归属或关键接触参数带）执行精确条件化分支重解，按**预期可消除的歧义测度比例（Measure Split）**排出最优复核顺序，最快将「有据歧义」坍缩为「确定贯通」或「确定断开」。

## 三、真实露头基准实验结果

正式实验基于两处公开可核查的真实岩石露头数据集与一处中国钻孔编录格式参照：
- **巴西 Jardim Garcia 玄武岩采石场**（Zenodo `10.5281/zenodo.7220755`, CC-BY-4.0）：60,343,162 点 → 预注册 $6\text{ m}\times 6\text{ m}$ 窗口 1,279,478 点 → 46 片有限面 → **6 个真实裂隙簇**（其中 3 簇保留真实拓扑孔洞）；
- **意大利 Finale Ligure 灰岩露头**（Perozzo et al., 2024）：83,208,117 点 + 1,405 个专家拟合结构面与三维迹线 → 按空间象限构建 **16 个条件有限多边形簇**；
- **中国甘肃北山钻孔编录**（22 口钻孔、880 条结构面）：用于深度/倾向/倾角观测算子字段格式映射（因缺三维体内真值，不纳入三维贯通准确率分母）。

### 1. 同一批 21 个完备真实簇上的三方定量对照

22 个真实簇中，**21 个完备簇**在预算内完成全空间精确认证（枚举 **132,000 对三角形**、**22,399 个可达接触窗口**、**10,551 个精确原子格**，纯 CPU 求解总耗时 **89.42 秒**，零 GPU、零训练），认证分布为 **1 个确定贯通 + 14 个确定断开 + 6 个有据歧义**；第 22 簇（`jardim_c01`）需 5,024 格超过 4,096 格预算上限，单列「超预算拒答」。

| 方法 / 基线 | 评价分母与子项 | 实测结果 | 风险与机理说明 |
|---|---|---|---|
| **名义单一模型（Nominal DFN）** | 21 个完备簇（静默翻转率） | **6 / 21（28.57%）发生静默翻转** | 3 例将断开误判为贯通，3 例将贯通误判为断开，且无任何风险提示 |
| **朴素多实现并集图（Union Graph）** | 14 个确定断开簇 / 6 个有据歧义簇 | 真断开簇误报 **0 / 14**；歧义簇 **6 / 6（100%）单边报通** | 把不同状态的接触边叠成一张图，完全掩盖合法的断割反例 |
| **本文精确四态认证** | 21 个完备簇（声明模型范围内静默误判） | **0 / 21（0.00%）** | 该定则定，该疑则疑；6 个歧义簇并列输出连通路径、S/T 最小割与稳定裕度 $\rho \in [0.0873, 1.6448]$ |

### 2. 6 个真实歧义簇上的主动复核消歧效率（6,045 个根原子格同分母对比）

| 复核排序策略 | 平均消歧步数（测度加权） | 首步消除歧义比例 | 三步累计消除歧义比例 |
|---|---:|---:|---:|
| **本文 · 测度分裂（Measure Split）** | **2.05 步** | **57.02%** | **85.38%** |
| **本文 · 精确极小极大（Minimax）** | **2.30 步** | **31.84%** | **80.53%** |
| 最大面积几何启发式 | 3.99 步 | 10.52% | 49.73% |
| 随机复核基线（20 固定种子） | 4.65 步 | 23.93% | 50.12% |
| 尺寸 / 距离综合启发式 | 4.92 步 | 11.81% | 45.57% |

### 3. 三重独立可复核防线
- **独立盲算复核（M3）**：独立判卷程序零源码共享（AST 静态审计 0 违规引用，仅用 Python 标准库从原始分数坐标重算），**22 / 22 簇状态与规范 JSON 哈希 100% 一致（0 分歧）**；
- **异常注入与回归防线**：36 项独立异常注入测试（凸包隐蔽填洞、颠倒通断结论、篡改 1 字节源文件、注入无关裂隙干扰排序）100% 拦截 + 290 条平台单元回归全部通过；
- **预注册时间锁**：选簇与端点规则冻结时刻（`2026-11-20T14:52:28Z`）严格早于建簇时刻（`15:34:31Z`），杜绝事后挑样。

### 4. 明确研究边界（三项 `null` + 一项超预算）
本项目严格区分几何筛查与未实测外推，凡未建立实测分母的指标一律显式记为 `null`（绝不填 `0`）：
- **地下深部无条件真值误判率 = `null`**（露头仅观测表层，体内微 CT / 透明岩体受控真值列为下半程任务）；
- **水力导通与涌水量预测 = `null`**（当前为几何贯通必要前提筛查，耦合开度、充填物与独立渗流求解器列为下半程任务）；
- **现场人工实测省时 = `null`**（`2.05 步` 为反事实信念树仿真步数，不等同于现场野外工时）；
- **第 22 簇 `jardim_c01` = 超预算拒答**（需 5,024 格 > 4,096 格上限，下半程引入有理分层包围盒与区间剪枝扩容至 65,536 格）。

## 五、快速开始与一键复现

### 1. 环境准备
- Python 3.10+（科学计算基础库：`numpy`, `scipy`, `matplotlib`, `python-pptx`, `python-docx`；精确求解与独立盲算核心仅依赖 Python 标准库 `fractions`）

### 2. 启动本机 STRATA 三维工作台演示
```powershell
# 无窗启动本机离线 3D 双见证与主动复核演示台（默认端口 127.0.0.1:8855）
pythonw results/midterm_sprint_20261120/M5_strata_workbench_demo/launch_strata_demo.pyw

# 或启动公网同款轻量只读三维展示站（默认端口 127.0.0.1:8860）
python deploy/strata_showcase/server.py --host 127.0.0.1 --port 8860
```

### 3. 一键复跑独立盲算判卷（M3）与交付验收
```powershell
# 1) 独立盲算复核全部 22 个真实裂隙簇（零求解器源码引用，纯标准库重算）
python results/midterm_sprint_20261120/M3_independent_judge/judge_real.py `
  --m1 results/midterm_sprint_20261120/M1_real_to_exact_bridge `
  --m2-run results/midterm_sprint_20261120/M2_active_identifiability/runs/run_20261120_exact_v1 `
  --out-dir results/active_runs/m3_recheck

# 2) 一键运行全套门禁与中期交付物 48 项一致性核验
python workflows/run_gates.py

# 3) 一键导出干净独立的 GitHub 发布包（自动剔除大体积原始点云与过程缓存）
python workflows/05_export_release/export_clean_release.py --github-clean --out ./dist_github_release
```
